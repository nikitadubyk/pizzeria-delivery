# Загрузка данных

Для страниц и блоков с запросами используйте `Details` из `components/details`.
Он отображает `Loader`, ошибку с повторной попыткой или содержимое.

```tsx
<Details
  isLoading={isLoading}
  isFetching={isFetching}
  isError={isError}
  errorMessage="Не удалось загрузить рестораны"
  onRetry={refetch}
>
  <RestaurantList restaurants={data?.items ?? []} />
</Details>
```

- `isLoading`: вместо содержимого отображается загрузчик.
- `isFetching`: содержимое остаётся смонтированным; оверлей и `inert` временно
  блокируют клики и фокус клавиатуры, сохраняя состояние блока.
- `isError`: отображается сообщение. Кнопка «Повторить» доступна, если передан
  `onRetry`. Во время повторного запроса вместо ошибки показывается загрузчик.
- `loadingLabel`: доступное название загрузки, например «Проверка входа…».
- `className`: размеры и компоновка постоянного внешнего контейнера во всех состояниях.
  Внутри страницы задавайте доступную высоту через flex/grid; Loader занимает её целиком.

Передавайте флаги запроса явно. При нескольких зависимых запросах объединяйте
их состояния и повторяйте завершившиеся ошибкой запросы в `onRetry`.
Не включайте для тех же запросов глобальный `AppLoader`.

Для отдельного индикатора используйте `Loader` из `components/loader`:

```tsx
<Loader label="Загрузка меню…" className="min-h-60" />
```

`components/ui/loader` остаётся перекрывающим слоем для `AppLoader` и основой
нового загрузчика. Сохранение, удаление и отправка формы используют `loading`
на кнопке, которая запускает операцию. Ошибки этих операций не заменяют форму.

Состояния и интерактивный повтор запроса представлены в Storybook:
`Components/Details`.
